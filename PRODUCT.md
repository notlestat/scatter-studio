# Scatter

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated by Corey on 25 October 2026. TypeScript, Vite and native web controls; WebGL2 particle rendering and a shared geometry model for vector export and portable embeds.

## Users
Corey making experimental image-led graphics and interactive website elements.

## Product Purpose
Turn up to four pictures into an art-directable moving point field. Match the working tools observed on Gather Lite, then add SVG export and a reusable interactive website embed.

## Operating Context
Local browser editor. Artwork exports must be usable independently of the editor. Publication and deployment are outside this request.

## Capabilities and Constraints
Picture upload and switching, swarm/melt transitions, drift/splash/gather/depth, line position/angle/side, orbit/zoom/pointer interaction, tracking/links/scan/trails/marks, tracker density, paper and negative/true appearance, coloured light impulses, fullscreen and keyboard shortcuts. SVG, PNG, project save/load, interactive HTML and JavaScript embed are requested implementation scope. Match capabilities, not the reference's code or identity. Semantic depth requires an explicitly labelled model download; processing stays local. Brightness relief remains available when inference fails.

## Evidence on Hand
User-provided https://gather.be-of-dao.com/. Public page and two scripts captured 25 October 2026 under docs/research/reference for private analysis only. REA runtime capture and static analysis evidence are recorded in docs/research. Code-level observations do not by themselves prove runtime behaviour. No original application code or branding is licensed for reuse by this request.

## Product Principles
- The picture leads; controls remain discoverable.
- Every exported result uses the same point geometry as the editor.
- Explain depth and export limitations honestly.
- All images and project data are processed locally.
